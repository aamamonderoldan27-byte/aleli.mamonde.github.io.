## Consulta 1

- **Fecha:** 16/11/2026
- **Herramienta utilizada:** ChatGPT
- **Objetivo:** organizar una estructura HTML semántica para el portfolio.
- **Prompt completo:**  
  “Necesito una estructura semántica para un portfolio personal de una estudiante de sexto año interesada en desarrollo web y programación. Incluí encabezado con navegación, presentación, Sobre mí, Proyectos con tres trabajos, Habilidades, Contacto y pie de página. Usá HTML5, etiquetas semánticas, enlaces internos con id coincidentes y marcá la información que deba verificarse. No inventes datos personales ni evidencias.”
- **Parte utilizada:** estructura general del documento, `header`, `nav`, `main`, `section`, `article` y `footer`, además de enlaces internos.
- **Cambios realizados por mí:** se adaptaron los textos a la identidad profesional y a la planificación previa; se eligió el nombre visible y se organizaron las cinco secciones solicitadas.
- **¿Qué comprendí?:** HTML organiza el contenido y las etiquetas semánticas describen la función de cada parte. Los enlaces internos deben coincidir con el `id` de su sección.
- **¿Qué descarté y por qué?:** se descartaron datos personales no necesarios, formularios complejos y funciones que no son necesarias para la versión 0.1.

## Consulta 2

- **Fecha:** 16/11/2026
- **Herramienta utilizada:** ChatGPT
- **Objetivo:** crear un diseño CSS inicial, adaptable a celulares y coherente con la identidad visual planificada.
- **Prompt completo:**  
  “Mi portfolio tiene un estilo creativo, minimalista y tecnológico. Usa lila suave (#C8B6E8), violeta oscuro (#4B3B75) y blanco. Debe transmitir creatividad, claridad y responsabilidad. Creá una hoja CSS inicial con variables de color, tipografía legible, espaciados, tarjetas de proyectos, estados hover y adaptación a pantallas pequeñas. Usá CSS puro, sin frameworks ni animaciones complejas. Explicá qué hace cada bloque y cuidá el contraste.”
- **Parte utilizada:** variables de color, estilos de navegación, tarjetas, botones, distribución responsive y estados de foco.
- **Cambios realizados por mí:** se mantuvo la paleta lila elegida en la planificación, se organizó la presentación en dos columnas para escritorio y una columna en celular, y se añadieron estilos de foco visibles.
- **¿Qué comprendí?:** CSS controla la presentación visual; las variables permiten reutilizar colores y las media queries adaptan el diseño a diferentes anchos de pantalla.
- **¿Qué descarté y por qué?:** se descartaron frameworks, animaciones complejas y elementos decorativos que pudieran dificultar la lectura.
