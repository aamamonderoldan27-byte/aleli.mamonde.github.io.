# Portfolio personal - Agostina Alelí Mamonde Roldán

Primera versión (0.1) de un portfolio personal para Aplicaciones Informáticas II, 6.º E.

## Contenido
- `index.html`: estructura semántica con Presentación, Sobre mí, Proyectos, Habilidades y Contacto.
- `css/estilos.css`: diseño responsive con paleta lila, violeta y blanco.
- `bitacora_ia.md`: registro de dos consultas de IA.
- `GUIA_PUBLICACION.docx`: pasos para crear el repositorio y activar GitHub Pages.

## Cómo probarlo
Abrí `index.html` con un navegador. Para modificar el diseño, editá `css/estilos.css`.

## Antes de publicar
Revisá las descripciones de proyectos, confirmá las tecnologías y tu participación, agregá evidencias reales si las tenés y reemplazá el enlace general de GitHub por tu perfil público cuando lo crees. No incluyas datos personales sensibles.

## Publicación
El sitio está preparado para GitHub Pages. La creación de la cuenta, el repositorio y la activación de Pages requieren iniciar sesión en la cuenta personal de GitHub.
